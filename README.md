## 🤖 Is repo ke agents

Claude Code me ye subagents available hain (`.claude/agents/`):

| Agent | Kaam |
|---|---|
| `progress-tracker` | Din start/complete karna, tasks tick karna, status batana, sab kuch regenerate + commit |
| `note-taker` | Aaj jo seekha uske structured notes `notes/daily/` me likhna aur day se link karna |
| `daily-planner` | Aaj ka plan dena, pending/running/done ka review, pace check aur schedule adjust |

Manual CLI bhi hai:

```bash
python scripts/track.py status      # abhi kahan ho
python scripts/track.py next        # agla din
python scripts/track.py start D01   # din shuru
python scripts/track.py task D01 2  # task 2 tick
python scripts/track.py done D01    # din complete
python scripts/track.py sync        # sab files regenerate
```

```
data/curriculum/     day-by-day plan (source of truth, hand-written)
```
